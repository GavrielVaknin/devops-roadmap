# Projects

The building blocks. Each one is self-contained, follows the same template, and is meant to be understandable on its own by a reader who has never seen the rest of the repo.

## Numbering

`NN-kebab-case-name`, 2-digit zero-padded, ordered by dependency sequence (see `roadmap/project-dependencies.md`) — not necessarily by the date it was started.

## Starting a new project

1. Copy `_template/` to `NN-project-name/`.
2. Fill in the README per the template — including the Competency & Learning Objective links. A project without those links isn't scoped yet; see `docs/standards/project-lifecycle.md`.
3. Add a row to `roadmap/project-dependencies.md`.
4. Start the status log at `Idea` or `Proposed`, whichever is honest.

No numbered projects exist yet — the first one gets scoped once the competency map has real content to link against.
