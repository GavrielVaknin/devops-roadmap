# Journal

The professional learning journal for this project — public, dated, one file per day when there's something to record.

This is not the place for personal, freeform reflection (how a session felt, motivation, unrelated noise). That lives in a private companion journal kept outside this repository, by deliberate choice — see the discussion this decision came from if it's ever formalized as an ADR.

## Convention
- Path: `docs/journal/YYYY/YYYY-MM-DD.md`
- One file per day with an entry. Not every day needs one.

## Template

```markdown
# YYYY-MM-DD — [Project NN] short session title

**Time spent:** ~Xh
**Project:** [link]
**Related objective(s):** LO-00X

## Objective for this session
What was I trying to do today?

## What I did
Chronological, brief. Not a tutorial — just the trail.

## What I learned (in my own words)
The important part. Explain the concept as if teaching it to someone who
has never heard of it. If I can't, I don't understand it yet — that's fine,
write down where the understanding breaks.

## Friction / blockers
What didn't work, and how long did I fight it before finding the fix?

## Next step
What's the very next thing to do, so future-me doesn't have to reconstruct
context.
```
