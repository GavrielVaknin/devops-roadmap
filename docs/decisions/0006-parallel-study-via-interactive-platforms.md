# 0006. Supplement project work with parallel interactive-platform study

Date: 2026-08-12
Status: Accepted

## Context
Project work in this repo proceeds in dependency order, one competency at a time (see `roadmap/project-dependencies.md`). Separately, browser-based interactive simulator platforms were found for Python, Bash, Terraform, and Kubernetes — real shells, not passive video. A prior attempt at learning Python through YouTube videos alone did not lead to real retention.

## Decision
Study Python, bash scripting, Terraform, and Kubernetes in parallel with the sequential project roadmap, using interactive hands-on platforms, rather than waiting for the roadmap to formally reach each competency in order.

## Alternatives considered
- Strict sequential order only, no parallel study — rejected; this repo's dependency order reflects a sensible *project* sequence, not a restriction on when learning is allowed to happen.
- Passive video-only learning — already tried, rejected based on direct prior experience; didn't produce retention.

## Consequences
Exposure to some tools (Python, Terraform, Kubernetes) may now happen earlier than the roadmap's formal project sequence reaches them. This is fine as *exposure*, but real competency status updates and evidence should still only come from actual work done in this repo's projects — not platform exercises alone — to keep the evidence standard meaningful. Added "Scripting & Automation Fluency" as a new foundational competency in `roadmap/competency-map.md` to reflect this.
