# 0002. Name the repository devops-roadmap

Date: 2026-08-09
Status: Accepted

## Context
The repository needed a durable, public-facing name before the first commit. Requirements discussed: plain over clever, googleable, and it will be referenced on a CV, so it needs to read clearly to a stranger at a glance.

## Decision
Name the repository `devops-roadmap`.

## Alternatives considered
- `iac-journey`, `infra-as-code-lab`, `automation-roadmap`, `learning-devops` — all reasonable, none clearly better; `devops-roadmap` was preferred as the plainest and most immediately legible option.
- Naming it after evidence/portfolio framing directly (e.g. `devops-evidence`, `applied-devops-roadmap`) — considered, not chosen. Tradeoff noted below.

## Consequences
`devops-roadmap` is also a common name for curated link-list curricula on GitHub (roadmap.sh-style "things to learn" repos), which is not what this repository is. A stranger skimming the name alone might expect a bookmark list rather than an evidence-based project log. Mitigation: the top-level README states explicitly, in its first paragraph, that this is not a link list — every project is something actually built. This is judged sufficient; the name itself does not need to change.
